# VivahSutra

A mobile-first Indian wedding invitation maker concept.

## Current build
- Premium maroon, ivory and antique-gold visual identity
- Responsive landing page and invitation template gallery
- Working category filters
- Invitation details form with live preview
- PWA manifest and custom app icon

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

## Current limitations
This is a front-end prototype. It does not yet have accounts, cloud saving, AI generation, payment processing, downloadable invitation exports, or a production database. The current editor preview runs locally in the browser.

## Next milestones
1. Simple and advanced invitation editor
2. Real image/template assets and regional collections
3. Export to image/PDF and WhatsApp sharing
4. Optional accounts and cloud-saved designs
5. AI design assistance and payment flow, after provider and cost decisions
